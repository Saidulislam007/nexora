# Nexora Interactive Studio

A responsive creative-studio portfolio built with Next.js App Router, TypeScript, and Tailwind CSS. The hero includes a smooth cursor-driven image trail.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

Main source files live in `src/app` and visual assets live in `public`.
